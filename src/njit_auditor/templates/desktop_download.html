Open and audit

  1. Download the ZIP and choose Extract all in Windows. Keep the entire extracted folder together.
  2. Open the folder and double-click NJIT Thesis Auditor.exe. Python is included; no command prompt or installation is needed.
  3. Select a PDF in the browser page, then choose Start audit. Findings and reports are generated on your computer.
  4. Save reports you need and choose Quit when finished. Closing only the browser tab leaves the local application running.

The app uses your default browser and needs no internet connection for auditing. Review findings manually against NJIT guidelines.

Release notes and updates

This edition combines local PDF auditing with short corrections, optional explanations, highlighting, filters, and PDF, text, Markdown, and JSON reports.

Updates are manual. Quit the old version, download the complete new package, and extract it into a new folder. The app does not check for updates or download code in the background.
