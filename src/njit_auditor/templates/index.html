What you get

What it checks

PDF uploads run P011–P082 heuristic layout checks (P082 experimental/opt-in; disabled by default in the web UI). TeX and ZIP uploads run P001–P010 source checks without compiling the project. ZIP support audits LaTeX source files — it does not generate or audit a compiled PDF. All findings are advisory signals — please verify against NJIT guidelines manually.
