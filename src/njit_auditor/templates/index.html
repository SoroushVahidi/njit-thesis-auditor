What it checks

Runs P011–P056 heuristic formatting checks: margins, page numbering, heading styles, TOC/List alignment, font compliance, front-matter structure, copyright page, spacing, and more. TeX source audit is available via the CLI only.

Uploaded files and downloaded PDFs are processed locally and not committed to any repository. Findings contain structural metadata only — no document body text is stored or displayed. Public URLs are validated for scheme and resolved host before download; private/internal addresses are blocked.
