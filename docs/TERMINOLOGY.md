# Terminology

## Verified spelling: Ester Flaim

Use **Ester Flaim** in new public prose. NJIT's [official directory entry](https://people.njit.edu/profile/ef264)
identifies her as Assistant Director, Graduate Studies. Authorized project correspondence
corroborates this spelling and role.

An earlier version of this note incorrectly instructed writers to use “Esther.”
That note is not evidence for a person's name. The About Us verification corrects it;
older prose may retain the earlier spelling until a relevant, scoped edit is made.

Keep existing `ester_*` and `esther_*` code identifiers, fixture names, paths, and
sample IDs unchanged for compatibility. This correction does not authorize a bulk rename.

## "Initial MVP" language

Earlier documentation (including the top-level `README.md`) described this project as "the
initial MVP." As of this audit, the project implements P001–P083 (82 rules), has a deployed web
UI under continuous iteration, and is materially beyond an initial MVP stage. This audit removed
that phrase from `README.md`; if you find it elsewhere, it's safe to update — it's descriptive
language, not a versioned claim anything depends on.
