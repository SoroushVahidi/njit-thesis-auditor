# Ester Materials Sources

This repository includes three raw Ester-provided files in `data/raw/ester/`:

- `260330_YESNO_audit_logic_matrix.xlsx`
- `Yin_Haotian_Second_R_with_EF_Feedback.pdf`
- `Yin_H_4th_Review_with_EF_comments_compressed.pdf`

Origin:
- Files were uploaded via the private GitHub repository and pulled into local `main` before reorganization.

Usage:
- `260330_YESNO_audit_logic_matrix.xlsx` is the source for extracted front-matter compliance rules.
- `Yin_Haotian_Second_R_with_EF_Feedback.pdf` is a review artifact for comment-pattern examples.
- `Yin_H_4th_Review_with_EF_comments_compressed.pdf` is a compressed PDF review artifact for comment-pattern examples.

Notes:
- The 4th-review file is a compressed PDF version and is not the original DOCX.
- Keep the repository private and do not share student dissertation/review files.
- Avoid external paid APIs or cloud document-processing services for these files.
- Processed rule/example outputs should not include full dissertation body text.
