# Native Windows x64 acceptance checklist

Use **only synthetic PDFs**. Record the Windows edition/build, Python builder version, commit SHA, package SHA-256, commands, exit codes, screenshots, and a network trace in a dated evidence directory. A Linux build, Wine run, or passing source tests do not satisfy these gates.

1. On a native Windows x64 builder with a clean committed worktree, run `powershell -ExecutionPolicy Bypass -File scripts/build_offline_windows.ps1`. It must build the one-folder package, find only the eleven allowlisted project resources, show one listener at `127.0.0.1`, reject unauthenticated PDF/report/page requests and invalid Host with HTTP 403, and stop that listener. Review the dated `njit-offline-windows-smoke-*` directory under `%TEMP%` for `result.txt` and both launcher logs. The script intentionally does not put a session ticket in an evidence file.
2. Copy the **entire** built `dist\NJIT Thesis Auditor` folder to a separate clean Windows x64 user profile with no Python installation. Double-click `NJIT Thesis Auditor.exe`; confirm the default browser opens the audit page without terminal use. Check executable signing, antivirus/SmartScreen behavior, and whether the distribution method is acceptable for this user.
3. Confirm `Get-NetTCPConnection -State Listen` shows only `127.0.0.1` for the application process. Capture application-process DNS and connection activity with Windows network tracing; investigate every non-loopback destination. Keep browser, extension, Windows Update, and operating-system traffic separate from application traffic.
4. Before using the launcher URL, request `/`, `/audits/unknown/pdf`, `/audits/unknown/download/json`, `/audits/unknown/download/student-report.pdf`, and `/audits/unknown/highlighted-page.pdf?page=1` without a session; each must return 403. Try an invalid Host, invalid Origin, and mutation with a missing or invalid CSRF token. Confirm the launch ticket works once and a replay returns 403.
5. Audit synthetic normal, actual Unicode, rotated-page, and low-text PDFs. Compare JSON findings, rule IDs, issue types, severity, pages, measurements, locations, explanations, coordinates, highlighted pages, and report contents with the online app on the same commit. Verify filters, sorting, page/problem navigation, original and highlighted PDF links, and JSON/Markdown/text/combined PDF downloads in a real browser.
6. Submit malformed and encrypted synthetic PDFs. Confirm a helpful failure page, no local profile path or PDF text in the browser response or launcher logs, and no leftover invalid-upload workspace. Verify oversized requests are rejected with 413.
7. Inspect `%LOCALAPPDATA%\NJIT Thesis Auditor`: private per-user access, expected `audits` and `tmp` contents during an audit, **Delete this audit**, **Delete all local audit data**, and Quit cleanup. Delete while an audit is active; it must finish or stop safely and remove queued data. Force-kill a synthetic run, relaunch, and verify abandoned audit and temporary files are removed. Verify a report manually saved outside the managed directory survives deletion.
8. Attempt a second launcher instance; it must fail without deleting the first instance's active data. Quit through the browser and, separately, through the launcher window if present; no listener or unnecessary application process may remain. Confirm session expiry stops access and eventually shuts down the service.
9. Unplug networking or disable the network adapter, then repeat a normal synthetic audit and report download. The application must still work. Scan the package for original dissertations, private samples, evaluation ledgers, private notes, credentials, and unexpected project resources; no such data may be present.

Every item must be marked PASS with evidence before claiming Windows release readiness. Record FAIL or NOT TESTED explicitly. These checks do not establish secure disk erasure or certify confidentiality. The browser, browser extensions, synced profile, download folder, backup services, and operating system can retain or transmit data independently of the application.
