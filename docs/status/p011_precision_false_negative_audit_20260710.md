## 8. Confirmed false negatives

### A. Non-text margin violations (systemic gap)

`run_pdf_margin_rule` audits **text lines from `page.text_blocks` only**. It does **not** inspect:

- raster images (`page.get_images`)
- vector drawings (`page.get_drawings`)
- table borders / figure frames
- annotations

Sample A: 23 image instances, 243 drawing paths — **none margin-checked**.  
Sample B: 8 image instances, 393 drawing paths — **none margin-checked**.

A figure or table extending past the margin without a violating text bbox would **not** produce P011. This is a **documented follow-up**, not shipped in this PR (no synthetic FP-safe prototype met the conservative bar).

### B. Boundary-near text (intentional suppression)

All boundary-crossing text within 3 pt tolerance or low-confidence single-line sub-5 pt is intentionally omitted — not false negatives.

## 10. Duplicate / volume analysis

P011 dominates visible results because margin violations are **per page and per side** at detection time, then **deduplicated for display**:

| Mechanism | Behavior |
|-----------|----------|
| Same page, same side | One visible card (`consume_p011_finding_visibility`) |
| Same page, multiple sides | One rolled-up card (anchor = lowest raw index) |
| Multiple spans per line | Union bbox; one raw finding per side |
| Overlapping block/line | Single line index path — no duplicate raw findings |

Sample A: 19 raw → 17 visible (2 multi-side rollups on pages 92, 98).  
Sample B: 27 raw = 27 visible (no rollups needed).

**Recommendation:** keep current grouping; do not collapse distinct sides or pages.
