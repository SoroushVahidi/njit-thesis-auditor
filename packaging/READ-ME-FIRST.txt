NJIT THESIS AUDITOR — DESKTOP

Target platform: Windows 10 or Windows 11, x64.
Release candidates require native Windows testing before student distribution.

1. Right-click the downloaded ZIP and choose Extract All.
2. Keep the entire extracted NJIT Thesis Auditor folder together.
3. Double-click NJIT Thesis Auditor.exe. Do not run it inside the ZIP.
4. In the browser page, select a PDF and choose Start audit.
5. Review the findings and suggested fixes. Open highlighted pages and save
   PDF, text, Markdown, or JSON reports as needed.
6. Choose Quit in the page or launcher window when finished. Closing only
   the browser tab does not quit the application.

No Python installation, command prompt, administrator access, or internet
connection is needed for auditing. A default browser is required.

Your PDF is processed on this computer, not sent to a document server.
Temporary files: %LOCALAPPDATA%\NJIT Thesis Auditor\audits and \tmp.
Delete this audit or Delete all local audit data removes working copies;
Quit clears them too. Startup removes abandoned work after interruption.
Downloaded reports remain where you save them. Deletion is not secure erasure.

Each audit stops after two minutes, including queueing. Use Cancel audit
to stop it sooner. If it times out, try a smaller PDF or audit it again.

Findings are advisory. Check the NJIT requirements and obtain human review.
Edit your original document and export a new PDF before auditing again.

Updates are manual: Quit, download a complete new ZIP from the approved
website, and extract it into a new folder. No automatic network update checks
run. About shows the version and source revision.

If Windows warns about the download, verify the publisher and checksum through
the approved distribution channel. Do not disable antivirus or bypass school
security policies. Contact support if Windows prevents the app from opening.

To remove the app: Quit and delete its extracted application folder. Saved
reports and the local data directory can be removed separately if no longer needed.
